# Subhankar Giri — 3D Developer Portfolio

A modern, high-performance personal portfolio built for **Subhankar Giri**, Data Scientist & Data Analyst.

## Features

- **3D Developer Workstation:** Realistic 3D scene of Subhankar's digital workspace built with Three.js, React Three Fiber & Drei, complete with dual monitor IDE code display, typing animations, lighting, and mouse parallax.
- **11 Core Sequential Sections:**
  1. Home (`#home`)
  2. About Me (`#about`)
  3. Technical Skills (`#skills`)
  4. Project Showcase (`#projects`)
  5. Verified Certifications (`#certifications`)
  6. Academic Journey (`#education`)
  7. Professional Experience (`#experience`)
  8. Quantified Achievements (`#achievements`)
  9. GitHub Analytics & Heatmap (`#github`)
  10. Curriculum Vitae & Resume (`#resume`)
  11. Contact & Collaboration (`#contact`)
- **Admin Panel & Dynamic Database Storage (`/admin`):** Full client-side persistent storage using IndexedDB / LocalStorage for dynamic CRUD of projects (up to 5 screenshot uploads), certificates, resume PDF replacement, and achievements.
- **Performance & Smooth Scrolling:** Integrated Lenis smooth scrolling synchronized with GSAP ScrollTrigger ticker.
- **Aesthetic Identity:** Dark notebook / IDE-inspired theme with deep navy background, neon pink primary accent, and cyan secondary accent.

## Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + PostCSS
- **3D Graphics:** Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations:** GSAP, GSAP ScrollTrigger
- **Smooth Scroll:** Lenis
- **Icons:** `react-icons`
- **Email Service:** `@emailjs/browser`
