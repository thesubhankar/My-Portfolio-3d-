# CERTIFICATIONS SECTION — Certifications.jsx

PURPOSE
Display certificates in a clean recruiter-friendly way.

EACH CARD
- Certificate image/thumbnail
- Certificate title
- Issuing organization
- Date if available
- Credential/view icon
- Credential URL if available

DESIGN
- Compact professional cards.
- Certificate image gets a clean frame.
- Avoid large "View Certificate" text buttons.
- Prefer recognizable credential/link icons.

ANIMATION
- Cards reveal with a stagger.
- Certificate image has subtle scale on hover.
- Credential icon gets a small lift/glow on hover.
- Use opacity + transform for smoothness.

MOBILE
- Single-column cards.
- Images must remain readable.

IMPORTANT
Do not fabricate certificate names, organizations or dates.
