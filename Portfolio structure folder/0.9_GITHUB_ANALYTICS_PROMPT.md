# GITHUB ANALYTICS SECTION — GithubAnalytics.jsx

PURPOSE
Present GitHub activity as a technical credibility section.

CONTENT
- GitHub profile link
- Repository count when real data is available
- Commit/activity information when real data is available
- Contribution graph/heatmap
- Relevant GitHub stats
- GitHub profile button

DESIGN
- Multiple responsive statistic cards.
- Contribution heatmap must remain readable.
- Keep the existing portfolio's dark analytics/dashboard feel.
- Use clean labels and recognizable GitHub icon.

ANIMATION
- Statistic cards count/reveal only when real data is loaded.
- Cards stagger on scroll.
- Heatmap fades in progressively.
- Do not animate every heatmap cell individually if it hurts performance.

DATA RULE
Never display fake GitHub numbers.
If live API data is not implemented, show configurable placeholders or clearly marked unavailable values.

MOBILE
- Stats become a 2-column or 1-column layout.
- Heatmap must remain usable without horizontal page overflow.
