Make the resume easy to view and download.

CONTENT
- Resume/CV preview card
- Short professional statement
- View Resume button
- Download Resume button

FILE
Use:
public/resume.pdf

DESIGN
- Clean document-style card.
- Resume icon/thumbnail.
- Strong but simple CTA buttons.

ANIMATION

- Do not use distracting animation.

FUNCTIONALITY
- View button opens the PDF appropriately.
- Download button downloads the PDF.
- Verify the path works in production.

MOBILE
