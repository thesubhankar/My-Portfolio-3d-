# ABOUT SECTION — About.jsx

PURPOSE
Explain Subhankar's professional background and career direction in a concise, trustworthy way.

CONTENT
- Short About Me introduction
- Data Science background
- Data Analysis background
- Current technical focus
- Career objective
- 3–4 professional highlights

LAYOUT
- Main text block plus compact highlight cards.
- Use notebook/code-inspired labels where appropriate.
- Keep paragraphs readable.

ANIMATION
- Section title reveals from below.
- Main paragraph reveals line/block by block.
- Highlight cards stagger into view.
- Cards move upward slightly with opacity.

SCROLL BEHAVIOR
- Trigger animation once when approximately 70–80% of the section enters viewport.
- Avoid replaying excessively.

INTERACTION
- Highlight cards have subtle border/glow response.
- No excessive 3D rotation.

IMPORTANT
Do not invent qualifications or achievements. Use only supplied information.
