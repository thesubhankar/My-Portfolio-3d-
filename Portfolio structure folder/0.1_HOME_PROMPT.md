# HOME SECTION — Home.jsx

PURPOSE
Create the first impression of the portfolio. It must immediately communicate who Subhankar Giri is, what he does, and provide clear actions.

CONTENT
- Profile photo
- Name: Subhankar Giri
- Role: Data Scientist & Data Analyst
- Short professional introduction
- Primary CTA: View Projects
- Secondary CTA: Download/View Resume
- Social icons: GitHub, LinkedIn and relevant links
- Optional small status line inspired by the existing "Python 3 | idle" notebook UI

LAYOUT
Desktop:
- Strong hero composition.
- Profile/visual area and text should feel balanced.
- Keep enough empty space for a premium look.

Mobile:
- Stack content vertically.
- Profile image remains prominent.
- Buttons become easy to tap.

ANIMATION
1. Page loading completes.
2. Hero container fades in and moves upward slightly.
3. Name reveals smoothly.
4. Role appears after the name.
5. Description appears next.
6. CTA buttons appear with a short stagger.
7. Profile image has a subtle scale/fade entrance.
8. Add a very subtle floating/glow effect only if it does not reduce performance.

GSAP
- Use a timeline for the entrance sequence.
- Use opacity + y/scale.
- Do not use large dramatic movements.

INTERACTION
- CTA buttons have subtle magnetic/scale hover.
- Social icons have a small lift/glow.
- Profile image can have a subtle border glow on hover.

IMPORTANT
The Home section must look impressive without becoming visually crowded.

# HOME SECTION — 3D DEVELOPER WORKSTATION

## 1. CORE CONCEPT

Create a premium, cinematic, modern 3D developer portfolio homepage.

The main visual concept is:

**"A Developer Working Inside His Digital Workspace"**

Instead of a car or outdoor scene, the hero section should show a realistic 3D version of **Subhankar Giri** sitting at a modern developer workstation.

The visitor should feel like they are entering my personal digital workspace.

The scene should look like a combination of:

- Premium developer desk setup
- Modern software engineering environment
- Futuristic technology workspace
- Cinematic 3D presentation
- Personal portfolio

Do NOT make it look like a gaming room.

Do NOT make it look like a generic stock developer image.

The 3D character should be the visual identity of the portfolio.

---

# 2. 3D CHARACTER — MY PERSONAL AVATAR

Create a realistic 3D character representing **Subhankar Giri**.

The character should be based on my real appearance whenever a suitable reference photo is provided.

Important:

- Preserve recognizable facial structure from the provided reference
- Keep natural proportions
- Professional hairstyle
- Realistic skin/material rendering
- Natural body proportions
- Modern professional clothing
- No cartoon/anime appearance
- No exaggerated superhero appearance

The final result should feel like:

**"My real self converted into a premium 3D digital avatar."**

If a reference photo is available, use it consistently for the character throughout the scene.

Do not randomly change the character's face between animations.

# 6. CINEMATIC INTRO ANIMATION

When the website loads:

### Stage 1 — Dark workspace

Start with a mostly dark scene.

Only subtle monitor/LED lighting is visible.

### Stage 2 — System startup

Monitor slowly turns on.

Small ambient lights activate.

### Stage 3 — Camera movement

Camera slowly moves toward the desk.

Use a cinematic camera movement.

### Stage 4 — Character reveal

The 3D character becomes visible sitting at the workstation.

Character performs a subtle natural movement:

- adjusts posture
- moves hand toward mouse/keyboard
- looks toward monitor

Keep the movement natural.

### Stage 5 — Portfolio reveal

Camera slowly shifts from the 3D workspace toward the hero composition.

Portfolio content fades in.

### Stage 6 — Final hero state

Character remains in the workstation scene while the portfolio hero content is clearly readable.

Target intro duration:

**3–5 seconds.**

Do not make the visitor wait too long.

# 23. PERFORMANCE

3D performance is extremely important.

Use:

- Optimized GLB/GLTF models
- Compressed textures
- Lazy loading
- Limited polygon count
- Limited lights
- Limited particles
- Device-aware quality
- Reduced effects on mobile

Do not create an unnecessarily heavy 3D environment.

Target a smooth experience.

---
