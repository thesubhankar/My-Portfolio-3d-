# ACHIEVEMENTS SECTION — Achievements.jsx

PURPOSE
Show awards, competitions, hackathons and meaningful accomplishments.

EACH ITEM
- Achievement title
- Event/organization
- Short explanation
- Date if available
- Optional proof/link if available

DESIGN
- Premium achievement cards.
- Use small icons for awards/recognition.
- Avoid excessive decoration.

ANIMATION
- Cards reveal with stagger.
- Icon has a subtle scale/glow entrance.
- Hover produces a small lift and border glow.

MOBILE
- Single-column layout with comfortable spacing.

IMPORTANT
Do not fabricate achievements or rankings.
