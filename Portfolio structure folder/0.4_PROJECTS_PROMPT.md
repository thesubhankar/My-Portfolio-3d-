# PROJECTS SECTION — Projects.jsx

PURPOSE
Showcase projects as the strongest proof of practical skills.

EACH PROJECT CARD MUST SUPPORT
- Project image
- Project title
- Short description
- Technologies used
- GitHub link
- Live demo link when available

DESIGN
- Medium-sized cards, not oversized cards.
- Use the existing portfolio's visual identity.
- Project image should be visually dominant.
- Technology tags appear below the description.
- GitHub/live actions use clean icons.
- Responsive grid or controlled carousel.

ANIMATION
- Section title reveals on scroll.
- Project cards stagger in.
- Images subtly scale on hover.
- Card moves upward a few pixels on hover.
- Border/glow reacts to hover.
- If carousel is used, arrows appear cleanly in free space and controls remain accessible.

GSAP
- Use ScrollTrigger for reveal.
- Use short, smooth hover timelines.
- Avoid heavy continuous effects.

MOBILE
- One card per row or a touch-friendly horizontal carousel.
- Do not make controls too small.

IMPORTANT
Do not invent project results, metrics or technologies.
