# SKILLS SECTION — Skills.jsx

PURPOSE
Present technical skills clearly for recruiters.

CATEGORIES
1. Programming — Python
2. Data Analysis — Pandas, NumPy, EDA
3. Visualization — Matplotlib, Seaborn, Power BI, Tableau
4. Machine Learning — Scikit-learn, Regression, Classification, Clustering
5. Deep Learning — TensorFlow, Keras, Neural Networks, CNN
6. Databases — SQL, MySQL, SQLite, PostgreSQL
7. Tools — Excel, Jupyter Notebook, Anaconda, VS Code
8. Version Control — Git, GitHub
9. Deployment — Flask, FastAPI, Streamlit

DESIGN
- Category-based cards.
- Use recognizable icons/logos.
- Do not use fake percentage bars.
- Keep card sizes consistent.
- Use responsive grid.

ANIMATION
- Section heading reveals first.
- Category cards stagger from bottom with opacity.
- Individual skill chips/icons appear with a small stagger.
- On hover: subtle lift, border glow and icon scale.
- Avoid continuous animations on every skill.

MOBILE
- 1 column or 2-column grid depending on width.
- Keep text readable and cards compact.

IMPORTANT
Do not claim skill percentages unless real data is supplied.
