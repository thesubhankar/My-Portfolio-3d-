# EDUCATION SECTION — Education.jsx

PURPOSE
Present academic background clearly.

CONTENT
For each education entry:
- Degree/program
- Institution
- Duration/year
- Relevant details if supplied

DESIGN
- Use a clean timeline or stacked cards.
- Timeline should work on both desktop and mobile.
- Keep dates visually distinct.

ANIMATION
- Timeline line can reveal progressively.
- Each education item enters with a stagger.
- Date badge and content card can reveal together.
- Keep movement subtle.

MOBILE
- Convert timeline to a simple vertical stack.
- Avoid cramped horizontal layouts.

IMPORTANT
Use only actual education details supplied by the user.
